# Knowledge Grapher

From zero to knowledge graph. Tap into structured context with a simple web app. Make a knowledge graph for anything. Person, job, project, tool, topic, idea. Seed it in minutes, keep it current, integrate with AI tooling as JSON and Markdown. For [humans](https://nhinternesch.github.io/knowledge-grapher/) and [agents](https://nhinternesch.github.io/knowledge-grapher/llms.txt).

**Private by default.** The graph lives in the browser's local storage until it is exported.
